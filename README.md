# Silpo Order Management System (POS)

Консольна інформаційна система для керування замовленнями, автоматизації розрахунків та обліку продажів у супермаркеті «Сільпо». Проєкт реалізований на мові **C++** з використанням об'єктно-орієнтованого програмування (OOP).

---

## Особливості (Features)

* **Динамічний каталог:** Завантаження актуального списку товарів та цін із зовнішнього CSV-файлу (`list_product.csv`).
* **Інтерактивний кошик:** Додавання товарів, автоматичний підрахунок одиниць виміру (шт, кг), оновлення кількості та видалення позицій.
* **Гнучка система знижок:** Підтримка фірмових промокодів (наприклад, `SILPO2026` дає знижку 10%).
* **Збереження чеків:** Автоматична генерація детального текстового чека (`receipt.txt`) з часом покупки.
* **Аналітика та Логування (JSON):** Накопичення історії всіх транзакцій у єдину базу даних `all_receipts.json` за допомогою сучасної бібліотеки `nlohmann/json`.
* **Юніт-тестування:** Проєкт повністю покритий 10+ автоматичними тестами через *Microsoft Native Unit Test Framework*.
* **Аудіо-супровід:** Інтегрована фонова музика через Windows Multimedia API (`winmm.lib`), що працює в асинхронному режимі.

---

## Архітектура проєкту

Проєкт структурований відповідно до професійних стандартів розробки:
* `Silpo.h` — оголошення класу `SilpoOrder`, структур даних (`Product`, `CatalogItem`) та статусів замовлення (`OrderStatus`).
* `Silpo.cpp` — повна реалізація бізнес-логіки системи.
* `main.cpp` — консольний інтерфейс користувача (CLI) з меню керування.
* `UnitTest_Silpo.cpp` — набір тестів для перевірки стабільності та безпеки логіки програми.

## Як запустити проєкт

### Системні вимоги:
* Операційна система: **Windows** (необхідна для роботи аудіо та MS Test).
* Середовище розробки: **Visual Studio 2022** (або новіша) з установленим робочим навантаженням *Desktop development with C++*.

### Інструкція з запуску:
1. Клонуйте репозиторій або завантажте сирцевий код.
2. Відкрийте файл рішення `Silpo.sln` у Visual Studio.
3. Переконайтеся, що конфігурація збірки виставлена на **Debug | x64**.
4. Додайте аудіофайл `background.wav` у папку проєкту для активації фонової музики.
5. Натисніть **Ctrl + F5** або кнопку **Local Windows Debugger** для запуску програми.

## Запуск Юніт-Тестів

1. У верхньому меню Visual Studio оберіть **Test** -> **Test Explorer**.
2. У панелі, що відкриється, натисніть кнопку **Run All** (зелений трикутник).
3. Переконайтеся, що всі тести пройшли успішно (горять зелені галочки).
